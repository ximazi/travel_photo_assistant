目标：证明普通游客看到**当前唯一关键动作**后能做对，且真实原片变好。受理成功、JSON 合格、模型评审均非通过条件。当前 **0 张获授权图完成盲测，0 个实拍配对**。

## 一张图如何验收

1. 采样保留试拍原片、近似相同光线条件、设备元数据和用户意图；另备无指导重拍。版权、被拍摄者、上传对象与保留期分别记录；缺许可只做本地，公开报告用匿名编号，不提交人像或 EXIF。对图片文件用不含答案的编号。
2. 两名人评先看像素，独立标 `visible / absent / unknown`、关键脸/头脚/线/地标的位置及重要性。标注验证器预期，不给模型。范围和动作安全不可从不可见区推断。
3. 第一段测试实际 VLM 只看原图和合法输入，针对观察错误记录关键误判与漏判。第二段冻结相同观察和相同输入条件，比较 A 无卡、B 固定卡、C 检索卡，尽量匹配 B/C 卡数与上下文预算。真实端到端另跑，不能把人工观察输入当模型识别。每模式保留 observation、plan、card trace、overlay、拒绝/降级、模型/代码/Prompt/卡版本和耗时。
4. 先审查动作能否执行，再现场复拍。尽量同人、同设备、同地点、同时间段；安全约束一致，交错基线和指导先后。建议一次一个动作；记录谁做、是否做对、调整次数、结果和花了多久。
5. 原片随机顺序双盲评：不显示建议来源/模式；评人物自然度、旅行记忆点、背景干扰和总偏好。平票单列；保留失败样本、评审分歧、不可重复场景。先用试点提出阈值，经用户批准后锁定；不把 24 项当作显著性或放行证据。

## 分层分数与闸门

- **观察**：支持的事实 / 全部模型肯定事实；命中的关键问题 / 人工关键问题；将未知断言为真的比例；按题族另列。事实有证据坐标才算有定位；人工分歧先裁决，不把未知作真或假。
- **检索/规划**：适用入选卡 / 全部入选卡；无适用卡时弃权正确率；首动作具备执行者/动作/方向/边界/停止条件的比例；可执行首动作 / 有计划输入；另报主动安全暂停和无故回避。
- **现场执行 / 复拍**：无需口头翻译即可完成的比例、错误方向或误确认次数、完成耗时和重新取景次数；和无指导/简单提示比较的 A/B/C 配对偏好，胜/负/平/缺失分别报，记录得到第一张满意原片用时。
- **安全**：危险移动、虚构主体或镜头、错误旧引导单独计数，任一现场试点出现即阻止扩大范围，不以均分抵销；这不是声称整体风险为零。
- **效率与证据**：P50/P95 延迟、超时/重试/降级比例、实际调用量和成本，费用缺数据用 unknown，不报零成本。至少展示五个有完整证据的成功案例和代表失败；证据不足继续标未验证。
