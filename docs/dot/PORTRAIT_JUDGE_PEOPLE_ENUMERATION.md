# 人物列举诊断 v0.1

关联 #31 / Draft #32。独立事实诊断，不替换 v0.2 美感评分或 v0.4 观察试验，不把“唯一一人”和“是视觉主体”混在一起。

[完整提示词](../../assets/prompts/portrait_people_enumeration.system.txt)不告诉模型目标人数。模型逐张看背景、边缘和远处，只报告可见实例、归一化位置、有何视觉依据、是否存在可能藏人的不可读区域。用 [JSON Schema](../../assets/prompts/portrait_people_enumeration.schema.json) 作为 Ollama 的 format，先检查输出结构和重复 JSON 键，再调用 `scripts/portrait_people_enumeration.py` 的 `audit_pair`，换序后映射回原图来源。单独记录格式错误、未知、事实判断。

程序判“恰好一人”：两处空间上可区分的确认框就失败，即使另有可疑候选；仅一人、全图可读且无可疑候选才通过；看不清、可能有额外人物、或只有疑似重复的重叠确认框则未知。完整扫描没有确认或可疑候选才按零人判失败。框交集达到较小框面积的一半即视为可能重复，不在这一步断言二者是同一人；规则是保守的位置近似，不是身份核验。模型自报“扫描完整”也不是完整率证明。程序不能核实文字证据或框是否真的对应人物。

## 遮挡反例与下一组开发样本

补充两个纯程序回执反例（不是照片或模型失败）：同一人的头和身体被遮挡物隔断，若误填成两个不交叠确认框，v0.1 会错误判失败；两个独立人框高度重叠时，v0.1 会判未知。两项测试记录当前行为，不表示缺陷已修复。离线相关套件 **37/37**。不改阈值、不改默认管线，也不打开或推理六张封存盲评图。

另选未经本轮调优的开发实拍：一张仅一名真人但可见部位被障碍物分隔，一张两名真人明显互相遮挡但仍各有可辨认的头部或躯干线索。提前标记同一实例的分离可见区域与不同人的独立线索；独立标签缺位就标为开发目视记录。对照方案应让模型先描述可见证据，并区分“同一人”“不同人”“无法判断”；只有看得见的独立线索才支持不同人的判定，禁止用框交叠率断言身份。若无独立线索仍报未知。两张训练用反例不能单独作为更换规则或调整阈值的依据。
