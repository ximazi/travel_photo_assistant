# v0.4 试验：模型观察，程序判定

关联 #31 与 Draft #32。**只用于开发对照，不替换 v0.2，不回填旧回执。** 使用 [v0.4 完整提示词](../../assets/prompts/portrait_quality_review.observation_experiment.system.txt)。保留 v0.3 试验的适用范围说明，原五维、权重和 5 分平局边界不变。

将拍摄任务预先拆成 `goal` 和 `required_elements`。每条硬要求给不含答案的唯一 ID，例如 `{"id":"q2","criterion":"喷雾中有可见彩虹"}`；正面和否定式都按条件是否满足记录 `pass/fail/unknown`。模型对每条给状态、区域和具体证据，另外评目标整体是达成、部分达成、未达成或不确定。模型不算总分、不投胜者。

程序先检查**完整**回执：两张图和五个维度齐全，必拍项 ID 恰好覆盖输入、不能重复，判断和值域合法、证据不为空。即使另一条硬要求已失败，也不能忽略缺失、重复或畸形的证据。对通过结构验证的结果：任一硬要求 `fail` 则意图 0；否则任何硬要求 `unknown` 则意图未知；全部通过才保留整体目标判断（2/1/0/未知）。美感按既有权重另算。只有正序和反序按来源归一后都一致，才保留该比较结论；不明和无效都不能变成稳定胜出。结构正确不是画面事实正确。没有依据不自动填补。

运行 `python scripts/portrait_observation_verdict.py <pair.json>`，文件最外层键为 `brief`、`forward`、`reverse`。其中 `brief` 如 `{"goal":"旅人在体验间歇泉","required_elements":[{"id":"q2","criterion":"喷雾中有可见彩虹"}]}`；其余两项是按呈现顺序收集的原始 v0.4 JSON 对象，缺失用 null。输出每次校验/判分及归一后的稳定结果。

## 验证（本地，不含人评）

- Windows 新增 9 项、原有 10 项共 **19/19** 离线单测。包括 fail+unknown、pass+unknown、全通过不把「部分达成」升级为「达成」、重复或缺失 ID、坏证据、空回执、换序翻转和旧版本保持独立。
- [DEV-03](PORTRAIT_JUDGE_ELIGIBILITY_EXPERIMENT.md) 两张相同的预处理图继续只在本地 Qwen3-VL 4B 测试，两次换序，不重试。温度 0，上下文 8192，JSON 模式。提示词 SHA256 `5b5a71ddfc624683ff044181aa27a3c5421e9062a2965aea937aacc611ca13f8`。正序 11.812 s，模型证据完整，程序将缺彩虹的 A 判意图 0、有彩虹的 B 判 2；美感 78.75 vs 83.75 恰差 5，判平。反序 3.985 s，原始观察中彩虹状态也映射正确，但模型把 `goal` 对象输出成字符串，**整份回执无效**，不宣布跨顺序胜出。没有新增外部模型调用，也没把该回执写成人评。
- 后续单独测试传输层强制结构输出（同提示词、同图、两次换序），观察是否修复结构错误。再验证多家族与更多开发样本，分开统计事实漏看、错误肯定和格式失败；不能仅靠本次彩虹对照上线。

## v0.4 结构化输出对照（同一提示词，只改生成约束）

用 `scripts/portrait_observation_schema.py` 的 `observation_schema(brief)` 生成约束，作为 Ollama `/api/chat` 的 `format` 对象传入，而不是 `"json"` 字符串。不把 schema 文本附加到提示词。保留 `abstain`、`unknown` 与空的硬要求列表；本地仍先检查重复 JSON 键，并用 schema 和 `adjudicate` 双重验证。Schema 不验证事实是否真实，且数组长度和 ID 值域正确也不能保证 ID 不重复。用已安装的 `jsonschema` 运行五项新增离线测试，连同旧用例 **24/24** 通过。

Windows 本地同一个 Qwen 检查点，温度 0、上下文 8192、最多 3000 输出 token，两张各呈现两次、不重试。前一节记录的提示词 SHA 未变。两组都使用同一对不含答案的 ID，schema 用 Python `json.dumps(schema, sort_keys=True).encode()` 后 SHA256 为 `87682139bca21f22cc7d70075bf2e1cd51204a6878b8cbfd4b6e49578fc3f3b0`。四次调用均完整结束、通过 schema 并获本地程序判分。此轮没有外部模型调用。

## 美感胜负的边界敏感性（离线回放）

`python scripts/portrait_beauty_sensitivity.py <pair.json>` 使用同一 v0.4 输入格式，校验回执、归一到原图 A/B 后输出有符号分差 `A−B`、同一原图实际换序变档的维度，以及哪些**一次只变一个单图单维、±1 档且仍在 0–4 内**的假设改动会改变胜负。未知不补零，无效不补分。假设改动是诊断，不是改票或把全部不确定性归于某个维度。阈值仍为 ≤5 分判平；各维度一档分别值 6.25 / 6.25 / 5 / 5 / 2.5 分。

复用上节已有 Qwen schema 回执，未发新模型请求：

- 海岸：A−B 从 +17.5 变成 0，A 的人物与场景、构图、姿态三个维度各降一档，B 五维完全不变；反序的平局对单档变化敏感。此例并非单档引起的实际翻转。
- 间歇泉：A−B 从 −5 变成 0，都在平局阈值内，但两个顺序的平局都可被某个合法单档变化打破。即使两个顺序结论一致，也不能把它当成可靠的人类审美平局。

新增 3 项离线检查，相关套件 **40/40**；不改权重、平局阈值或默认输出。后续在真人偏好旁报告这一诊断，不用这两组开发样本调整规则。
