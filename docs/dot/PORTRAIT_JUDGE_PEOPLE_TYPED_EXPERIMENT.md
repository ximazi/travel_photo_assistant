# 人数证据 v0.2：群体不等于一个人

本试验只验证拍摄目标中的「恰好一人」，不修改五维美感、权重、默认流程或正式盲评口径。没有看清，不等于没有人；模型画框，不等于框里的身份已由人工验证。

## 规则

模型只给三类证据：确定的单个人、群体区域、不确定形状。群体框不能通过「恰好一人」。两个独立可定位、互不重叠的可辨认头部轮廓，才把报告中的保守人数下界提高到 2，因此其余区域没看清也可判定不满足。重复群体框或同时报告群体及其成员不叠加人数。群体只给大框或没有足够的独立定位时，返回未知；同一个人被遮挡分开的身体碎片也不靠身体框距离判成两人。单人允许没有头部轮廓，但需要明确连贯的人体证据，整张图无其他疑点。完全扫清且没有候选人时判不满足，未扫清时判未知。格式无效不转成未知或通过。

像素语义仍靠模型：例如一个头部框错误地包住整个身体时，几何校验不能识别；两个人都只露身体或头部重叠时也可能弃权。本轮不从两张人群图调几何阈值，不把保守弃权当作识别正确。

## 下一轮优先项

评分主线优先：为构图、光线、姿态给出可被人类核对的 3→4 档锚点。3 表示支持拍摄意图且无关键缺陷；4 需要指出具体可见的摄影选择，以及去掉该选择会损失什么。剪影可有意使用，不因脸暗自动扣分；自然动作可胜过摆拍，华丽背景不替构图得分。先用独立开发图测试同图正反序的满分率和分差漂移，再与独立盲评偏好和有无指导的现场重拍比较；不能从这组人群样本调整美感权重。
