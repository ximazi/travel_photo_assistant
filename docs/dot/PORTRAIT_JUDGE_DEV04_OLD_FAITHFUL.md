# DEV-04 老忠实间歇泉：多人合框与美感满分偏多

开发集，不是留出、人评或重拍。两张由 NPS / Neal Herbert 拍摄于同一天，但不是同一拍摄任务或有无指导的一对。NPS 分别标注 public domain：[A 背光摄影者](https://npgallery.nps.gov/AssetDetail/af950f73-1d31-4e7e-a123-86eb8ae487fe)、[B 等候喷发的人群](https://npgallery.nps.gov/AssetDetail/1b4e9a09-559c-4a47-9f7d-7d034b4f35c9)。读取官方 medium JPEG，实际 1251×834 与 1371×914；同样按方向展开、RGB、长边 1200、JPEG 92 无裁剪去 EXIF，两张均 1200×800。SHA-256 为 `074e8aade12df74992a1adbe3a66acb7858d282e839db37c2027c5bb34efc1a8` 与 `0713502c7a8e86d6fd381222de41e5dd0bebfbf11897d569aff95ddd0069c325`；与六图盲评的来源和处理图哈希不重复。未发往 Gemini。

推理前目视：A 是一个有连续头、肩、身体的近景背光人物，正在用手机拍摄，不是“遮挡造成单人碎片”的测试。B 有整排访客，明显至少两人，部分重叠，但不是“只有两位高度重叠”的测试。喷发在两张均可读；A 人与喷发分居两侧、有明确姿态，B 更容易从人群看出尺度。目视记录不充当独立人评。

本地 Qwen3-VL 4B Q4，清单 digest `84f7ed8042fa7cdbd902f7dcb7d0370e032095047cc3244179f263b77b5bc318`，温度 0 / 8192 上下文 / 3000 输出 token。人数与美感各用冻结提示词与 schema。另有两次配图探针，保持旧海岸 A 在第一位且像素字节不变，只替换第二张（本组单人 / 人群，尺寸相同）。六次均正常停止、结构及本地规则校验通过，不重试。

**判断**：只检查结构再数框，仍会把自述是群体的一个框当作单人。两次出现的误放行同属一张图，不算两个独立案例。下一轮独立试验把每条证据明确区分“一个可辨认个体 / 包含可区分多人的群体 / 不明”，群体证据至少定位两个可辨认人物；只给人群框却没有足够分离线索时不得把它当作单人通过，不改几何阈值。美感还有“都高分”现象，下一轮在有独立偏好的更难构图、光线、姿态用例中检查满分依据，不从这组调整权重。
