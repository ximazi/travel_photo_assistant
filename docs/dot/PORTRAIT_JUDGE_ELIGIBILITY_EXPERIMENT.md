# Local eligibility-only development experiment

Issue #31, Draft #32; two development pairs, not a held-out benchmark. [v0.3 eligibility experiment](../../assets/prompts/portrait_quality_review.eligibility_experiment.system.txt) changes only the input-eligibility paragraph and revision label. Groups and non-dominant subjects are in scope when real people are visible. A failed shooting goal is scored, not grounds for refusing the comparison. v0.2 stays default; weights, output schema, tie rule and validator are unchanged. Both versions identify the same photograph tasks.

## DEV-03 (group and positive visual detail)

NPS / Jim Peaco public-domain [A](https://npgallery.nps.gov/AssetDetail/a4ffa78e-fb5c-4686-813b-f9c3cf1fe6ea) and [B](https://npgallery.nps.gov/AssetDetail/434d6cab-3dff-4d3b-b911-183cc6efbe96), original vertical photos from a single capture group 46 seconds apart. Brief: visitors watching an erupting geyser, with a visible rainbow in the spray. Pre-model assistant visual check, not independent human labeling: both show a group and erupting spray; B shows a red/orange-to-blue band in the left mist; a comparable band is not confirmed in A at this resolution. Beauty not labeled. At least one partly front-facing person is in the lower margin, so **keep these photos local only**; public-domain copyright does not grant unrestricted external processing in this project.

Upright, uncropped, EXIF-free inputs: A 791×1200 SHA256 `423c8864f81a4361c0f1b5d22b3f1da8d8a3d8cd4f644bbb4a85e0527909bed4`; B 811×1200 SHA256 `525a998dde948bf71c2849b45b2bfd9933f6feb832a3aa2cae8eb68ba882dbff`. Same prepared bytes in both variants. Prompt hashes v0.2 `a7f05fcd1e59355009ddf6ab580932e12db99ed8effc9785587f62b4d7eaa9f6` and v0.3 `6fc39e9f359e80da98543f71903a3ac52fcbb43782092ba4c068cff767b787d2`. Local Qwen3-VL with the same duration/temperature/config as DEV-02 (output cap 3000, context 8192, temperature 0), one request per order/variant, no retries. No cloud calls in this experiment.

| Pair | Qwen v0.2 | Qwen v0.3 eligibility-only |
|---|---|---|
| DEV-02 coastal, exactly one visible person | First order missed extra people and contradicted intent result; reverse abstained treating a goal failure as ineligibility. | Both orders attempt scoring, so the observed domain refusal is gone, but both miss the extra people. First still self-contradicts; reverse accepts a tie; no stable outcome. 10.547 s / 7.390 s. |
| DEV-03 geyser/rainbow | First order flags rainbow absent in A, present in B, but gives A intent 1 despite the hard miss (invalid); reverse reports rainbow in both and ties. 10.093 s / 7.985 s. | Correct raw rainbow statuses both ways, but both outputs omit required per-axis evidence objects (bare scores) and give the photo without a rainbow full intent score. 7.250 s / 4.172 s. Both invalid; findings are diagnostic only. |

Decision: do not promote this revision or Qwen as an automatic judge. Track (1) scope/abstention, (2) localized visual detection, (3) evidence completeness, and (4) rule application separately. Next experiment should make hard-failure enforcement and A/B aggregation deterministic from supported model fields, while still rejecting missing per-axis evidence. A separate transport experiment may constrain JSON output; format enforcement alone cannot correct missed people, hallucinated rainbows, or full-score bias. Keep legacy v0.2 results unchanged, compare with more independently judged samples, and do not tune weights on these examples.
